# SceneOps — concept anchor

**Contest:** Manycore Aholo Global 3D AI Hackathon · Soft team SceneOps  
**Sponsor stack:** Aholo Lux3D (required) for core 3D generation  
**Language:** English materials

## Who / job

Field and booth ops leads (game jam booths, film previz, retail pop-ups) who need **runnable 3D props/set pieces in minutes**, not a full DCC pipeline.

## What changes

Today they either wait on artists or drop low-quality stock. SceneOps turns a short **ops brief** (prompt + optional photo) into a Lux3D GLB, shows it in a browser scene board, and attaches an **ops checklist** (placement, collision, print/export).

## Mechanism (Lux3D-core)

1. User enters scene brief → optional reference image  
2. Client calls **Lux3D text-to-3D / image-to-3D** (`G1` or `G1-Turbo`) with Global API Key  
3. Poll task → download GLB → mount in Three.js scene board  
4. Ops panel: badge “generated by Lux3D”, face budget, export notes  

Lux3D is not a logo: without the generate+poll path the product has no assets.
